Vitamin C 


Người bị đau dạ dày, bị viêm loét dạ dày thì càng phải bổ sung vitamin C, vì bị viêm dạ dày thì thiếu vitamin C trầm trọng, vitamin C giúp lành vết loét, hết viêm, tạo colagen, tăng cường hệ miễn dịch 

Vitamin c hấp thu tốt là loại L-ascorbic 

Vitamin C vô cùng quan trọng, ko thể thiếu, vitamin C có trong vitamin tổng hợp rồi nhưng vẫn phải bổ sung thêm viên vitamin C 

Vitamin C khi uống nên chia nhỏ liều ra để uống nhiều lần thì càng dễ hấp thu, mỗi lần uống khoảng 100-200mg, 1 ngày có thể uống từ 500-1000mg vitamin C tùy theo từng người.
